# KBO Knit UI

이 Storybook은 Lagrange 컴포넌트를 조합한 KBO Knit 화면을 확인하는 곳입니다.
**KBO Knit / Knitting Controls**에서 줄 수 계산 방식과 입력값 변경을 시험할 수 있습니다.
앱과 같은 `ThemeRoot`, `kboTheme`, reset과 글꼴을 사용합니다.

## 작업 범위

- 경기 결과, 뜨개 줄 수, 진행 기록과 화면 배치는 KBO Knit에서 관리합니다.
- Button, Dialog, 입력과 색상 선택기 등 공통 UI는 [Lagrange](https://github.com/fleetia/lagrange)에서 관리합니다.
- 공통 컴포넌트의 API와 개별 stories는 [Lagrange 컴포넌트 소스](https://github.com/fleetia/lagrange/tree/main/src/components)를 참고하세요.
- 테마 계약과 확장 방법은 [Lagrange theming 문서](https://github.com/fleetia/lagrange/blob/main/docs/theming.md)에 있습니다.

## 로컬 실행

KBO Knit은 GitHub Packages의 비공개 `@fleetia/lagrange` 패키지를 사용합니다.
패키지 인증을 준비하고 의존성을 설치한 뒤 `pnpm storybook`을 실행하세요.
전체 절차는 [KBO Knit 시작하기](https://github.com/fleetia/kbo-knit/blob/main/docs/getting-started.md)를 참고하세요.

Lagrange를 수정했다면 패키지 발행 후 KBO Knit의 의존성 버전과 lockfile을 갱신합니다.
로컬 Storybook은 패키지 발행이나 서비스 배포를 하지 않습니다.
